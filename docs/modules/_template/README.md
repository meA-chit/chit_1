# Module template

Copy `docs/modules/household/README.md` as the structure for a new module. Required sections: Purpose, Where this fits in the whole product, Submodules, Audiences and surfaces, Data this module owns, Dependencies, UI contribution, Privacy class, Module-specific rules, Status, Open questions.

Create in the same change: `docs/modules/<id>/{README.md,contracts.md,submodules/,stories/,decisions/}`, `modules/<id>/{README.md,module.manifest.yaml,submodules/,shared/}`, and add the module to `docs/00-overview/module-map.md`.
